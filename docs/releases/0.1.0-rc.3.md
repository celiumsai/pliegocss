# PliegoCSS 0.1.0-rc.3

> Candidate release record. Publication is not authorized by this document.
> The schema-3 [machine readiness record](../product/release-readiness-0.1.0.json)
> remains the current promotion authority.

RC.3 consolidates the post-RC.2 verification, distribution, and adapter work
into the next exact-version nineteen-crate compatibility unit.

## Highlights

- A shared pure `CompileRequest` / `CompileResult` engine across CLI, watch,
  macros, source scanning, and LSP.
- LSP semantic analysis without compiler child processes or synthetic source
  files.
- ThemeId and theme binary format 3, catalog schema 4, and inspection schema 3
  with explicit regeneration requirements.
- Benchmark Authority v2 against Tailwind CSS 4.3.3, Tailwind v3 LTS 3.4.19,
  and the frozen 4.3.2 regression lane.
- Browser/output certification contracts for Chromium, Firefox, and WebKit on
  Windows x64, Linux x64, and macOS ARM64.
- A repository-only native CLI/LSP distribution with SHA-256 manifests,
  CycloneDX SBOMs, GitHub/Sigstore attestations, and a no-lifecycle pnpm
  package that is never published to npmjs.
- Bounded Tailwind coexistence certification across 21 HTML, Vite, and
  PliegoRS project snapshots with exact rollback.
- Governed external-adoption intake that remains blocked until real reviewed
  interviews, incidents, and pilots satisfy G7.
- Framework-neutral consumption of the canonical
  `pliegors-product-topology/1` snapshot, keeping PliegoRS topology and
  PliegoCSS reachability/bundle planning aligned without a runtime dependency.

## Compatibility

The candidate preserves StyleId format 2, class-name format 1, and semantic IR
binary format 2. ThemeId and theme binary format move to 3. Consumers must
regenerate theme binaries, macro output, CSS, manifests, catalogs, indexes,
receipts, and class-keyed caches as one coordinated revision.

## Install

These commands become valid only after all nineteen crates are published and
the registry replay passes:

```console
cargo install pliego-cssc --version '=0.1.0-rc.3' --locked
cargo install pliego-css-lsp --version '=0.1.0-rc.3' --locked
```
