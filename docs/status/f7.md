## Current boundary

Schema 5 proves where emitted CSS came from. The generic collector proves that every visible macro
in its declared Rust inventory has explicit topology ownership. The PliegoRS adapter now additionally
derives that inventory from rustc dep-info for its exact three built targets and verifies the graph
and source bytes again after publication; this proof does not extend to unbuilt Cargo feature/target
permutations or other adapters. Usage analysis retains the all-compiled universe before
selected manifests are projected, so `unobserved` never aliases static deadness and removed
StyleIds keep exact tombstone evidence. Explicit retention can keep a reviewed dead StyleId only in
its named bundle; policy does not make it reachable or observed, and all selected artifacts share
the same schema-2 selection. `--prune-unreachable` still does not prune individual declarations,
but it filters `--theme` to variable-backed tokens consumed by retained semantic styles. Arbitrary
authored `var(...)` references remain outside that proof. The token report classifies only the
active resolver selection and retained semantic consumers; it is not runtime evidence or a global
deletion grant. The product registry remains application-owned even
though its adapter proves exact-target CSS-source coverage and derives bundle partitions. The media
merge and pruning contract do not justify a global hybrid strategy or
a universal payload claim. Project Index is the implemented project-wide artifact contract, but it
is not yet an LSP transport or a generic framework collector.
