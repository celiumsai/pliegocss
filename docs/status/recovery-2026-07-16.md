## Scope

The local Git object database and most of the working tree were accidentally
deleted by a malformed cross-shell cleanup command. No remote or filesystem
snapshot containing the original `.git` directory was available, so the
original commit objects could not be restored.

The source tree in this recovery checkpoint was reconstructed from:

- an exact archive of historical commit `8858189`;
- the successful workspace patches recorded in the Codex session logs after
  that commit; and
- the surviving build output, used only as supporting evidence and never as a
  source of tracked files.

The reconstruction replayed 731 successful workspace patch operations in
their recorded temporal order. Failed patch attempts, external temporary
files, and generated cleanup-only paths were excluded. A file-by-file SHA-256
comparison between the reconstructed candidate and the restored workspace
reported 395 files and zero differences before lockfile regeneration.
