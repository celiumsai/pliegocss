## Current composition boundary

`pcx!` performs compile-time validation for the base and every visible branch. Each Cartesian result
is normalized and receives its own `StyleId`. Rust evaluates each clause once in source order and
selects one of those identities; it does not concatenate class fragments or generate CSS at runtime.

The `pliego-css-source` crate discovers macro literals and enumerates compositions. `pliego-cssc
--source path.rs` consumes that report, composes every selected branch semantically, and preserves
source ranges in the manifest. Build adapters still need to supply every relevant Rust source unit;
recursive Cargo module discovery is a separate concern.

## Gate state

Gate B is **closed as a conditional GO**. All 44 complete-fixture class attributes compile, all eight
fixture variants reach emitted CSS, 30/30 builds are deterministic, and gzip/transfer beat the
no-preflight Tailwind baseline. The Chromium smoke covers the frozen responsive viewports and key
states. Automatic Cargo/module and route/island collection, token-variable pruning, richer reusable
composition primitives, broader media equivalence/global grouping, the accessible cookbook, and a
multi-browser matrix remain release blockers rather than reasons to reopen the condition model.
Whole-rule pruning from an explicit sidecar is implemented. See the
[Gate B benchmark](../benchmarks/pliego-gate-b.md).
