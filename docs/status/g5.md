# G5 repository distribution status

Status: **architecture and local contracts implemented; exact-source hosted distribution evidence is
required before G5 can close for a candidate**

## Scope

G5 owns the native CLI/LSP and optional Node launcher distribution boundary. It does not change the
nineteen-crate crates.io compatibility unit and does not authorize a final release.

## Implemented contracts

- [x] Repository-only machine policy with npmjs publication forbidden.
- [x] Private universal `@pliegocss/cli` package with no dependencies or lifecycle scripts.
- [x] Shell-free host selection for Windows x64, Linux x64 GNU, and macOS arm64.
- [x] Native payload and aggregate manifest validators with PE/ELF/Mach-O guards.
- [x] SHA-256 asset inventory and CycloneDX 1.5 SBOM validation.
- [x] Local pnpm pack/bundle contract using three format-correct fixtures.
- [x] Hosted three-platform native build and three-platform pnpm install workflow.
- [x] Conditional GitHub/Sigstore binary, SBOM, and release-asset attestations.
- [x] Tag path creates only a draft release and fails closed when release immutability is disabled.

## Evidence still required

- [ ] A clean hosted workflow run on the final G5 source across all native and install lanes.
- [ ] One reviewed manual exact-source run with `attest=true` and successful `gh attestation verify`.
- [ ] Repository immutable releases enabled before any tag path is used.
- [ ] A newly named candidate whose tag, commit, tree, artifacts, SBOMs, checksums, and attestations
  all agree.
- [ ] Owner authorization before creating that candidate tag or publishing its draft Release.

RC.2 remains blocked because it predates these artifacts. Branch or later-candidate evidence cannot
be copied into its readiness record.
