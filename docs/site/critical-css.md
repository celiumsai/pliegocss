# Prove what rendered above the fold.

Join observed browser behavior to project topology and retained style identity without letting an observation silently authorize removal.

## Observe a real route {#observe}

Capture viewport, route, interaction state, loaded assets, matched styles, and source identities from a browser run against the built application.

## Join exact universes {#join}

Evidence is accepted only when its project index, asset plan, reachability, and CSS identities match the build under review.

## Observation does not equal deletion {#authority}

A style unseen in one scope remains unknown outside that scope. Explicit retention and reachability policies control removal authority.
