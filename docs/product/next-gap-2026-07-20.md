# Next evidence-driven gap: accessibility diagnostic quality

Status: **selected 2026-07-20; implementation not yet claimed**

The machine authority is [`next-gap-2026-07-20.json`](./next-gap-2026-07-20.json).

Phase 13 closed the reversible migration Should with durable, bounded, cross-platform local evidence.
The next locally actionable release blocker is therefore the accessibility diagnostic-quality corpus
required by R0.6 and R0.9.

The first slice is deliberately closed to declared literal, opaque, in-gamut sRGB contrast pairs. It
will label positive and negative cases independently of emitted findings and compute TP, TN, FP, FN,
precision, and recall. Existing unit tests remain implementation contracts; they are not counted as a
quality corpus.

This selection does **not** claim broad accessibility accuracy, runtime contrast inference, browser
validation, or WCAG certification. Hosted Firefox/WebKit/macOS evidence and published RC replay remain
blocked on external infrastructure or owner authorization.
