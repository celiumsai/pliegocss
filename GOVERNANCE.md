# Project governance

PliegoCSS is stewarded by Celiums Solutions LLC. Maintainers are responsible
for technical direction, release integrity, security response, and
compatibility of public contracts.

## Decisions

Small, reversible changes may be decided in a pull request. Public APIs,
serialized formats, security boundaries, supported platforms, or governance
changes require a public issue once the repository is open. The decision
record must state compatibility impact, alternatives, and verification
evidence.

Maintainers seek technical consensus. When consensus is not possible, the
project steward makes the final decision and records the rationale.

## Releases

Only maintainers may create official releases. A release must originate from a
reviewed default-branch commit, pass the documented gates, and preserve
provenance for distributed artifacts. Prereleases do not create a stable
support commitment.

Participation follows [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), vulnerabilities
follow [SECURITY.md](SECURITY.md), and marks follow
[TRADEMARKS.md](TRADEMARKS.md).
