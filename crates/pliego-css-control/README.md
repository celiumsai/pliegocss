# pliego-css-control

Closed canonical contracts for `pliego.css.manifest.json` and `pliego.css.receipt.json`. They bind
exact inputs, backend, targets, outputs, measurements, findings, checks, and result without a hash
cycle.

The optional `projection` feature supplies the CLI adapter for Source Map v3, token graphs, budgets,
SARIF, and bounded accessibility analysis. Schema-only consumers leave it disabled.

## Stability

Exact-version pre-release tooling; `0.1.0` is not published.
